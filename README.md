# Java の学習ツール

Java を習いはじめた人向けの、ブラウザだけで動くツールが2つ入っています。
どちらも Claude のアカウント・インストール・サーバーは不要で、コードやエラーはどこにも送信しません。

| ツール | こんなときに | 1ファイル版 |
| --- | --- | --- |
| **Javaその場チェック** | コードを**書きながら**、まちがいを横ですぐ知りたい | [`dist/java-sonoba-check.html`](dist/java-sonoba-check.html) |
| **Javaエラーやさしく解説** | `javac` / `java` が出した**エラーメッセージ**の意味を知りたい | [`dist/java-error-yasashiku.html`](dist/java-error-yasashiku.html) |

1ファイル版はダウンロードしてダブルクリックで開くだけで動きます。インターネットにつながっていなくても使えます
（そのときは文字の形だけが少し変わります）。メールやUSB、学校のLMSでそのまま配れます。

## Javaその場チェック

エディタに Java を書くと、打つ手が止まった瞬間（約0.2秒後）に、まちがいを

- **行の右**に短く（例：`「;」がない`）
- **横の一覧**に、直し方つきで（例：`→ 文の終わりに ; を書く`）

表示します。直せるものは「直す」ボタンで自動で直せます（Ctrl+Z で元に戻せます）。

- **エラー**（赤）… このままではコンパイルできない。本物の `javac` がエラーにするものだけを出します
- **注意**（黄）… コンパイルは通るけれど、実行時エラーやバグになりやすいもの

いま打っている行に新しく出たまちがいは、少し待ってから表示します（打ちかけのたびに「; がない」と出ないように）。
直したまちがいは、すぐに消えます。

### 見つけられるまちがい（主なもの）

| 種類 | 内容 |
| --- | --- |
| 書き方 | `;` 忘れ、`( )` `{ }` の不足・余分（字下げから場所を推測）、閉じていない文字列、`'abc'`、全角の記号・スペース・`“ ”`、`Public` など大文字の予約語、`for (i = 0, i < 10, i++)`、`"答え" x`（`+` 忘れ）、`if x > 0`、else の前に if がない、メソッドの外の命令、メソッドの中のメソッド、戻り値の型がない、`main(...);` の `;`、try だけ、`new Scanner;` |
| 名前 | 変数・メソッド・クラスが見つからない（「もしかして？」と直す候補つき）、`system`/`string` など大文字小文字、宣言より前で使っている、`{ }` の外で使っている、import 忘れ・import のつづりちがい、`new` 忘れ、`println` だけ |
| 型 | `int x = "5"`、`int n = sc.nextLine()`、`int x = 3.5`、`String s = 5`、`char c = "a"`、`if (x)`、`if (x = 5)`、`"a" - 1`、`0 < x < 10`、`char == "a"`、`(int) "5"`、`ArrayList<int>`、引数の数・型、戻り値の型 |
| 使い方 | `s.length`（`( )` 忘れ）、`arr.length()`、`list.length()`、`s[0]`、`list[0]`、`int` に `.`、`new List<>()`、abstract クラスの new、private、final への代入、static でないメソッド・フィールドを main から使う、static でない内部クラスの new、`@Override` のつづりちがい、インタフェースのメソッドを作っていない、public class とファイル名 |
| 流れ | 値を入れていない変数、`return` 忘れ、絶対に来ない文、`break`/`continue` の位置、変数の二重定義、`Thread.sleep` や `FileReader` の例外の対処忘れ |
| 注意 | 文字列を `==` で比べる、`i <= arr.length`、`i--` で終わらない for、条件の変数が変わらない while、`while (true)` から抜けられない、`if (...);`、整数どうしの割り算、0 で割る、配列の範囲外の番号、`nextInt()` のあとの `nextLine()`、`s.toUpperCase();` の結果を使っていない、switch の `break` 忘れ、`x =+ 1`、`name = name;`、`main` の形、`"¥n"` |

Java 21 の書き方（record、switch 式、パターンマッチ、テキストブロック、`var` など）にも対応しています。

### しくみ

すべて JavaScript で、ブラウザの中だけで動きます。

```
live.html           画面
src/lexer.js        コードを「トークン」に分ける。全角記号・閉じていない文字列などはここで見つける
src/parser.js       構文解析。書きかけでも止まらず、まちがいは1か所1つだけ報告して次の文から読み直す
src/types.js        型のあつかい（代入できるか、親クラス、メソッドの探し方）
src/checker.js      意味のチェック（名前・型・値の入れ忘れ・return 忘れ・届かない文・例外 など）
src/jdk-data.js     JDK 21 のクラス情報（自動生成。scripts/GenJdkData.java）
src/editor.js       エディタの動き（色分け・行の右の表示・一覧・直すボタン・キー操作）
```

方針は「**確実にコンパイルエラーになるものだけを『エラー』にする**。自信がないときは何も言わない」です。
別のファイルのクラスを継承しているなど、情報が足りないところではチェックをひかえます。

### キー操作

| キー | 動き |
| --- | --- |
| `F8` / `Shift+F8` | 次 / 前の指摘へ移動 |
| `Tab` / `Shift+Tab` | 字下げ / 字下げを戻す（複数行もOK） |
| `Enter` | 前の行と同じ字下げで改行（`{` のあとは1段深く） |
| `Ctrl+/`（Mac は `⌘+/`） | コメントにする / 戻す |
| `Esc` | エディタから出る（Tab で次のボタンへ移れるように） |

書いたコードは、このブラウザの中だけに保存されます（次に開いたときに続きから書けます）。

## Javaエラーやさしく解説

`javac` や `java` が出したエラーメッセージを貼りつけると、
**なにが起きたのか・よくある原因・なおし方・まちがい/正しいコード例** を、やさしい日本語で説明します。

- 英語のメッセージ（`error: ';' expected`）も、日本語のメッセージ（`エラー: ';'がありません`）も読めます
- エラーが複数あっても1つずつ分けて説明し、ファイル名と行番号、`^` の場所を表示します
- 実行時エラー（例外）は、スタックトレースから **自分のコードの行** を見つけます

### 対応しているエラー（50種類）

| 種類 | エラー |
| --- | --- |
| コンパイルエラー | `;` 忘れ、かっこ不足、シンボルが見つからない（import 忘れ・大文字小文字のまちがいも判定）、型が合わない、精度が失われる変換、public クラスとファイル名の不一致、`}` 不足、return 忘れ、未初期化の変数、到達できない文、文ではない、式の開始が不正、文字列/文字リテラルが閉じていない、static コンテキスト、変数の二重定義、例外の未処理、引数が合わない、演算子の型が不正、全角スペース・全角記号、文字コード、クラスの外の記述、戻り値の型がない、else に対応する if がない、final への代入、プリミティブ型に `.`、メソッド本体がない、abstract メソッド未実装、break の位置、配列でないものに `[]` |
| 実行時エラー | NullPointerException、ArrayIndexOutOfBounds、StringIndexOutOfBounds、IndexOutOfBounds（List）、0 で割り算、NumberFormatException、InputMismatchException、NoSuchElementException、ClassCastException、StackOverflowError、OutOfMemoryError、ConcurrentModificationException、FileNotFoundException |
| 準備・コマンド | `javac` が見つからない、ソースファイルが見つからない、メインクラスが見つからない、main メソッドがない、Java のバージョン違い |

```
index.html          画面
src/rules.js        エラーと説明の対応表（ここを増やせば対応エラーが増えます）
src/analyzer.js     貼りつけた文字を1つずつのエラーに分けて、ルールに当てはめる
src/app.js          画面の動き
```

ルールを足すときは `src/rules.js` に `rule({ id, kind, match, build })` を足します。上にあるルールから順に調べるので、
細かいルールほど上に置きます。説明文の中の `` `...` `` はコードとして表示されます。
追加したら、本物のエラー出力を `test/fixtures/` に入れて、`test/analyzer.test.js` の `EXPECT` に期待するIDを書いてください。

## 開発

```bash
npm test
```

```bash
npm run build
```

- `npm test` … 両方のツールのテスト。その場チェックは `test/live/` のコードで調べます
  - `test/live/ok/` … 正しいプログラム。**何も指摘しない**こと
  - `test/live/ng/` … まちがいのあるプログラム。行末の `// <<error:ID` / `// <<warn:ID` の行に、そのIDの指摘が出て、**ほかの行には何も出ない**こと
  - JDK が入っていれば、同じファイルを本物の `javac` でもコンパイルして答え合わせします（ok は通る、ng は同じ行でエラー、注意だけのものは通る）
- `npm run build` … `index.html`・`live.html` と `src/*.js` を、`dist/` の1ファイル版にまとめます。`src/` を書きかえたら作りなおしてください
- `npm run gen-jdk` … `src/jdk-data.js`（JDK のクラス情報）を、手元の JDK から作りなおします
