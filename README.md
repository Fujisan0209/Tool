# Javaエラーやさしく解説

Javaを習いはじめた人向けのツールです。`javac` や `java` が出したエラーメッセージを貼りつけると、
**なにが起きたのか・よくある原因・なおし方・まちがい/正しいコード例** を、やさしい日本語で説明します。

- 英語のメッセージ（`error: ';' expected`）も、日本語のメッセージ（`エラー: ';'がありません`）も読めます
- エラーが複数あっても1つずつ分けて説明し、ファイル名と行番号、`^` の場所を表示します
- 実行時エラー（例外）は、スタックトレースから **自分のコードの行** を見つけます
- すべてブラウザの中だけで動きます。貼りつけたエラーはどこにも送信しません

## 使い方

**いちばん簡単な方法:** [`dist/java-error-yasashiku.html`](dist/java-error-yasashiku.html) を1つダウンロードして、ダブルクリックで開くだけです。

- Claude のアカウントも、インストールも、サーバーもいりません
- インターネットにつながっていなくても動きます（そのときは文字の形だけが少し変わります）
- ファイル1つなので、メールやUSB、学校のLMSなどで、そのまま配れます

リポジトリをまるごとダウンロードした場合は、`index.html` を開いても同じように使えます。

`src/` を書きかえたら、`npm run build` で `dist/java-error-yasashiku.html` を作りなおしてください。

## 対応しているエラー（50種類）

| 種類 | エラー |
| --- | --- |
| コンパイルエラー | `;` 忘れ、かっこ不足、シンボルが見つからない（import 忘れ・大文字小文字のまちがいも判定）、型が合わない、精度が失われる変換、public クラスとファイル名の不一致、`}` 不足、return 忘れ、未初期化の変数、到達できない文、文ではない、式の開始が不正、文字列/文字リテラルが閉じていない、static コンテキスト、変数の二重定義、例外の未処理、引数が合わない、演算子の型が不正、全角スペース・全角記号、文字コード、クラスの外の記述、戻り値の型がない、else に対応する if がない、final への代入、プリミティブ型に `.`、メソッド本体がない、abstract メソッド未実装、break の位置、配列でないものに `[]` |
| 実行時エラー | NullPointerException、ArrayIndexOutOfBounds、StringIndexOutOfBounds、IndexOutOfBounds（List）、0 で割り算、NumberFormatException、InputMismatchException、NoSuchElementException、ClassCastException、StackOverflowError、OutOfMemoryError、ConcurrentModificationException、FileNotFoundException |
| 準備・コマンド | `javac` が見つからない、ソースファイルが見つからない、メインクラスが見つからない、main メソッドがない、Java のバージョン違い |

## ファイル

```
index.html          画面
src/rules.js        エラーと説明の対応表（ここを増やせば対応エラーが増えます）
src/analyzer.js     貼りつけた文字を1つずつのエラーに分けて、ルールに当てはめる
src/app.js          画面の動き
test/               テスト（fixtures/ は本物の OpenJDK 21 の出力）
```

## テスト

```bash
npm test
```

## ルールの追加

`src/rules.js` に `rule({ id, kind, match, build })` を足します。上にあるルールから順に調べるので、
細かいルールほど上に置きます。説明文の中の `` `...` `` はコードとして表示されます。
追加したら、本物のエラー出力を `test/fixtures/` に入れて、`test/analyzer.test.js` の `EXPECT` に期待するIDを書いてください。

# 満足化・ゲーム理論ラボ

条件を変えながら、**満足化**（ほどほどで決める）と**ゲーム理論**のシミュレーションをその場で試せるツールです。

**使い方:** [`dist/game-lab.html`](dist/game-lab.html) をダウンロードして開くだけです（インストール・サーバー不要）。

| 実験 | できること |
| --- | --- |
| 満足化 | 候補の数・1つ調べるコスト・分布・「あとで戻れるか」を変えて、最大化／満足化／妥協する満足化／見送り（37%）ルールの手取りを比べる。要求水準ごとの手取りの曲線から、ちょうどよい妥協点がわかる |
| 2×2ゲーム | 囚人のジレンマ・鹿狩り・チキンなどを選ぶか、利得表を書きかえて、ナッシュ均衡（純粋・混合）、支配戦略、パレート最適を自動で判定。最適反応の図とレプリケーター方程式の軌道（クリックで追加） |
| 繰り返し囚人のジレンマ | 得点 T/R/P/S、試合の長さ、ノイズ、満足化プレイヤーの要求水準を変えて、8戦略の総当たり戦と進化（レプリケーター・ダイナミクス）を見る |
| 空間ゲーム | 格子の上の囚人のジレンマ（Nowak & May）。誘惑 b や「満足していれば手を変えない」ルールで、協力者のかたまりがどう生き残るかをアニメーションで見る |

乱数はシードつきなので、同じ条件なら同じ結果になります。

```
game-lab/index.html     画面
game-lab/src/sim.js     シミュレーションの計算（画面に依存しない）
game-lab/src/app.js     画面の動き・グラフ
test/game-lab.test.js   計算のテスト
```

# テスト書き方道場

テストの書き方を練習できる、**採点つき**の練習ツールです。仕様を読んで JavaScript（Jest と同じ `test` / `expect` の書き方）でテストを書くと、その場で採点します。

**使い方:** [`dist/test-dojo.html`](dist/test-dojo.html) をダウンロードして開くだけです。

## 採点のしくみ（ミューテーションテスト）

問題ごとに、正しいコードと「1か所だけバグを仕込んだコード」を数個用意しています。

- **バグ発見 80点** … バグ入り版のうち、あなたのテストが1つでも落ちたものの割合
- **読みやすさ 20点** … 中身がわかるテスト名・どのテストにも expect がある・1テストの expect は4つまで
- **減点** … 正しいコードで失敗するテストは、テスト側のまちがい（1つにつき −10点。バグ発見にも数えない）

見逃したバグにはヒントが出て、「答えを見る」でどこを書きかえたバグだったかも確認できます。
テストは Web Worker で実行するので、無限ループを書いても3秒で打ち切られ、画面は固まりません。

## 問題（だんだん難しくなります）

| # | 問題 | 練習できること |
| --- | --- | --- |
| 1 | FizzBuzz | 同じルールの例を2つ以上ためす、型までくらべる `toBe` |
| 2 | うるう年 | 「ただし」がつく例外ルールを1つずつ |
| 3 | 成績のランク | 境界値分析、`toThrow` で異常系 |
| 4 | 配列の合計 | 空・1個・たくさん |
| 5 | 平均 | 小数の `toBeCloseTo`、空配列のエラー |
| 6 | クーポンの値引き | 切り捨て・下限など細かいルールが効く値を選ぶ |
| 7 | パスワードの点検 | 配列の `toEqual`、条件を1つずつ外す |
| 8 | スタック | 状態を持つクラス、操作の順番 |

```
test-dojo/index.html        画面
test-dojo/src/exercises.js  問題・正しいコード・バグ入り版・模範解答（ここに足せば問題が増えます）
test-dojo/src/runner.js     テストの実行（expect など）と採点
test-dojo/src/app.js        画面の動き・エディタ
test/test-dojo.test.js      どの問題も「模範解答で100点」「最初のテストでは満点にならない」ことを確認
```

問題を足すときは、`mutants` の `from` が正しいコードの中にちょうど1回だけ出てくるようにして、`npm test` で模範解答が100点になることを確かめてください。
