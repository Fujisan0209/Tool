# 声の感情メーター

マイクの声や音声ファイルから **感情を推定してグラフで表示する** ブラウザツールです。
インストール不要・依存ライブラリなし。音声はブラウザの中だけで処理され、外部に送信されません。

推定する感情: 😢 悲しみ / 😐 平常 / 😄 喜び / 😟 不安 / 😠 怒り

## 使い方

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます（マイクは https か localhost でのみ使えます。ファイル解析とデモは `index.html` を直接開いても動きます）。

- **マイクで開始** — リアルタイムで推定。最初の 5〜10 秒は普段の声で話すと基準が安定します
- **音声ファイルを解析** — WAV / MP3 / M4A など。全体を解析してから、再生位置とグラフが連動します
- **デモ音声** — 合成音声（平常→喜び→平常→怒り→平常→悲しみ→平常→不安）で動作を確認できます
- **CSV 書き出し** — 時刻ごとの各感情の確率・覚醒度・感情価・声の高さ・音量

## 表示されるグラフ

| グラフ | 内容 |
|---|---|
| いまの感情 | 最も強い感情と 5 感情の確率バー、覚醒度・感情価 |
| 感情の推移 | 各感情の確率の積み上げ面グラフ（なぞると内訳、クリックでその位置から再生） |
| 感情マップ | 横軸＝快↔不快、縦軸＝興奮↔落ち着き の円環モデル上の現在地と直近 4 秒の軌跡 |
| 声の高さ / 音量 | ピッチ (Hz, 対数軸) と音量 (dBFS) の推移 |
| 集計 | 発話時間のうち各感情が最も強かった割合（表表示あり） |

## しくみ

```
音声 ─▶ 50ms ごとのフレーム特徴 ─▶ 直近 1.5 秒の韻律特徴 ─▶ 話者基準で z 化 ─▶ 感情スコア ─▶ softmax ─▶ 平滑化
        (js/dsp.js)                 (js/emotion.js)
```

1. **フレーム特徴**（`js/dsp.js`）: 音量、ゼロ交差率、スペクトル重心、1kHz 以上の高域比、スペクトル平坦度、基本周波数（YIN 法）
2. **韻律特徴**: 声の高さ（中央値）、抑揚の幅、ピッチの細かな揺れ（2 階差分）、平均音量とその変化、明るさ、音節の速さ
3. **話者適応**: 声の高さやマイク音量は人によって違うため、その人の **中央値・MAD** を基準にした相対値で評価します。平均ではなく中央値なので、怒った区間などに基準が引っ張られません。ファイルは 2 パス（1 回目で全体から基準を作り、2 回目で推定）
4. **感情スコア**: 音声感情研究で知られる傾向をスコア式にしたもの
   - 怒り: 大きい・鋭い（高域が強い）・ざらつく
   - 喜び: 高い・抑揚が大きい・やや大きい
   - 悲しみ: 小さい・平板・低い・遅い・こもる
   - 不安: 高い・細かく揺れる・速い・小さめ
   - 平常: どの特徴も基準から大きく外れない

### 最適化

- ピッチ推定は ~16kHz に間引いてから YIN（計算量 約 1/9）
- FFT・窓関数・三角関数表をサイズごとにキャッシュし、作業バッファも再利用（フレームごとの GC なし）
- 1 フレームの解析 + 推定 ≈ 0.3〜0.5ms（50ms 間隔なので CPU 負荷は 1% 程度）。48 秒の音声のファイル解析は約 0.3 秒
- グラフは Canvas に **ピクセル列単位で間引いて** 描画するため、長時間の音声でも描画コストが一定
- 再描画は requestAnimationFrame で 1 回にまとめ、変化があったときだけ描画
- マイクの自動ゲイン・ノイズ抑圧・エコー除去は **オフ**（音量や声質の手がかりを壊すため）

## 注意

- 言葉の意味は使わず、声の調子（韻律）だけを見ています
- 学習済み AI モデルではなくルールベースの推定です。演技した感情や合成音声では分かりやすく出ますが、自然な会話では目安としてご利用ください
- 雑音が多い環境、複数人が同時に話す音声では精度が下がります

## テスト

```bash
node test/run.js
```

合成音声を使って、ピッチ推定の精度（±1%）、各感情区間の判定（16k / 44.1k / 48kHz × ファイル / リアルタイム）、処理速度を確認します。

## ファイル構成

```
index.html      画面
style.css       スタイル（ライト / ダーク対応）
js/dsp.js       音響特徴量（FFT, YIN, スペクトル特徴）
js/emotion.js   話者適応と感情推定
js/charts.js    Canvas グラフ
js/app.js       マイク・ファイル入力、UI
js/demo.js      デモ / テスト用の合成音声
test/run.js     テスト
```
