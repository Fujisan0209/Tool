# きもちの輪（感情ラベリング・ホイール）

ぼんやりした気持ちに、ぴったりの名前をつけるためのツールです。
プルチックの「感情の輪」をもとに、8つの基本感情 → 3段階の強さ → 細かい感情語（合計104語）へと掘り下げられます。

## 機能

- **ホイール**：3重の輪をタップすると、その感情にズームします。言葉ごとに意味・体のサイン・気持ちが伝えていること・対処のヒント・近い言葉・反対の感情を表示します。検索もできます（`/` キー）。
- **ガイド**：言葉が浮かばないときに、体の感覚（胸が重い、顔が熱い など）と、快／不快×エネルギーの2軸パッドから近い感情を提案します。
- **記録**：選んだ気持ちを強さ（1〜100）とメモ付きで保存します。2つ以上の基本感情を選ぶと、組み合わせ（例：喜び＋信頼＝愛）も表示します。
- **振り返り**：14日間の気分の波、基本感情の割合、感情の解像度（使った言葉の種類）、よく使う言葉。
- **書き出し・読み込み**：JSON / CSV（Excel対応のBOM付き）。
- オフライン対応（PWA）、ダーク／ライトテーマ、スマホ対応、キーボード操作、`prefers-reduced-motion` 対応。

## 使い方

ビルド不要です。`index.html` をブラウザで開くだけで動きます。
オフライン対応やホーム画面への追加を使うには、GitHub Pages など HTTPS で配信してください。

```bash
python3 -m http.server 8000
```

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML / CSS / JS をすべて含む。外部ライブラリなし） |
| `sw.js` | オフライン用のService Worker |
| `manifest.webmanifest` / `icon.svg` | ホーム画面に追加するための設定とアイコン |

記録はブラウザの `localStorage` だけに保存され、外部には送信されません。
