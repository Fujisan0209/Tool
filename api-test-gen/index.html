    選んだテストを、上から順にこのブラウザから送ります。API 側で CORS が許可されている必要があります。

    どんなテストを作るか

    • 正常系: 例や制約から正しいリクエストを作り、ステータスとレスポンスの形を仕様と照らします
    • 境界値: minimum・maxLength などのちょうどの値は受け付けるか
    • 異常系: 必須の欠落、型ちがい、範囲外、enum にない値、形式ちがいは拒否するか
    • 認証・404: 認証なしで拒否するか、存在しないIDで 404 を返すか

    使うときの注意

    • POST / PUT / DELETE はデータを変えます。テスト用の環境で実行してください
    • パスの値（ID など）は、実在するデータに合わせて書きかえてください
    • 対応: OpenAPI 3.0 / 3.1、Swagger 2.0（1つのファイルにまとめたもの）

    コマンドでも使えます

    CI で動かすときは node api-test-gen/cli.js 仕様書.yaml でファイルを書き出すか、--run でその場で実行できます。Node.js 18 以上だけで動きます。
