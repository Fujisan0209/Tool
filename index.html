Javaエラーやさしく解説

javac や java が出したエラーを貼りつけると、なにが起きたのか・どう直すのかを、やさしい日本語で説明します。英語のメッセージでも日本語のメッセージでも大丈夫です。

よくあるエラーで試す

どのエラーにも使えるコツ

  1. いちばん上のエラーから直す。 1つのまちがいが、そのあとのエラーをたくさん起こしていることがあります。1つ直したら、もう一度コンパイルしましょう。
  2. 行番号を見る。 Main.java:5: は「Main.java の 5行目」という意味です。実行時エラーは at Main.main(Main.java:8) の数字を見ます。
  3. ^ のあたりと、その1つ前の行を見る。 本当のまちがいは、少し前にあることがよくあります。
  4. 全角の文字をうたがう。 ； （ ” や全角スペースは、見た目が似ていても使えません。
  5. 直したら、ファイルを保存する。 保存し忘れると、同じエラーが出続けます。
コンパイルエラーjavac のときに出る。書き方のまちがい。直すまで実行できない。
実行時エラー（例外）java で動かしている途中に出る。書き方は正しいが、動かしたら問題が起きた。
準備・コマンドのエラープログラムではなく、ファイルの場所やコマンドの打ち方、パソコンの設定の問題。

貼りつけたエラーは、このページの中だけで調べます。どこにも送信しません。
