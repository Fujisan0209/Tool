仕様書から読む書き方

  • 見出しや箇条書きのシグネチャ（calcTotal(price: int): int、int calc(int a)、def f(a) -> bool）
  • 「引数」「戻り値」「フィールド」「定数」の見出し・ラベル・表
  • ## Order クラス の下の項目表、OrderStatus 列挙型 の値の並び
  • GET /api/orders/{id} の形の API、MAX_ITEMS = 100 の形の定数
  • 仕様書の中の ```java などのコードブロック
  • 文中の `名前`（コードにあるかだけ確かめます）
### calcTotal(price: int, qty: int): int
- 引数
  - `price` (int, 必須): 単価
  - `qty` (int): 数量。デフォルト 1
- 戻り値: int

コードから読むもの

  • Java: クラス・interface・enum・record、メソッド、フィールド、static final 定数、Spring の @GetMapping など、JAX-RS
  • TypeScript / JavaScript: function・アロー関数・class・interface・type・enum、export const 定数、Express の router.get(...)、NestJS
  • Python: def・class・dataclass・Pydantic・Enum、大文字の定数、FastAPI / Flask のルート

コンパイラではないので、とても珍しい書き方は読み落とすことがあります。node_modules などのフォルダは自動で飛ばします。
