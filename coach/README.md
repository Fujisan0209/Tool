# 学習コーチ（自分専用の学習AIコーチ）

演習の正答率や苦手を記録して、**次に出す問題を自動で選ぶ** 自分専用のコーチです。
忘れかけたころに復習を出す **間隔反復**、苦手な分野を見つけて重点的に出す **苦手分析**、
AI（Claude）による **記述問題の採点・まちがいの解説・苦手分野の問題づくり**、毎日の **定期実行** があります。

- 記録はすべて自分の PC の `data/` の中だけ。AI を使うときだけ、その問題と答えを Claude API に送ります
- AI なし（APIキーなし）でも、AI 以外の機能はすべて動きます
- 最初から「Java の基本」43問（9分野）が入っています。コードの出る問題は、本物の `javac` / `java`（OpenJDK 21）で答えを確かめてあります

## はじめかた

Node.js 18 以上が必要です。

```bash
cd coach
npm install
```

```bash
npm start
```

ブラウザで <http://127.0.0.1:4310> を開きます。選択問題は数字キー、次へは Enter で進めます。

ターミナルだけで解くこともできます。

```bash
node bin/coach.js quiz 10
```

### AI を使う

[Claude Console](https://platform.claude.com/) で APIキーを作り、環境変数に入れてから起動します。

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

| AI がすること | いつ | effort |
| --- | --- | --- |
| 記述問題（`free`）の採点と、ひとことアドバイス | 答えたとき | low |
| 「AIにくわしく聞く」: その人の答えのどこで考えがずれたかの説明 | ボタンを押したとき | medium |
| 苦手な分野の新しい問題づくり | 定期実行（1日1回、苦手な分野で未出題が3問未満のとき） | medium |
| コーチからのひとこと | 定期実行 | low |

- モデルは `claude-opus-5-5`（`COACH_MODEL` で変えられます）
- AI の答えは JSON の形を指定して受けとり（structured outputs）、受けとったあともプログラムで中身を確かめます。
  選択肢の数がおかしい・答えの番号が範囲外・既存と同じ問題文、などの問題は追加しません
- 安全のための判定で断られたときは、サーバー側で別のモデルが引きつぐ設定（`fallbacks: "default"`）にしています
- AI が作った問題には「AIが作った問題」と表示されます。おかしい問題は「この問題はおかしい」で止められます
- AI を使わないときは、記述問題は模範解答を見て自分で ○△× をつけます

### 1. 出題を選ぶアルゴリズム（`src/selector.js`）

すべての問題に点数をつけて、いちばん高いものを出します。

| 種類 | 土台 | 候補になる条件 | 加点 |
| --- | --- | --- | --- |
| relearn | 3 | このセッションでまちがえた問題（ほかの問題を3問はさんでから。3回まちがえたら今日はやめる） | |
| due（復習） | 2 | 思い出せる確率 R が目標（90%）を下まわった問題 | 目標からの下がり具合 ×2、苦手度 ×0.5 |
| new（新しい問題） | 1 | 解いたことがない問題（1日10問まで） | 苦手度 ×0.8、ちょうどよい難しさ ×0.5、カリキュラム順 ×0.2 |
| practice（おさらい） | 0 | 上の3つがないとき | 苦手度 ×0.6、忘れかけ具合 ×0.4 |

さらに、**直前と同じ分野は −0.5、2つ前と同じなら −0.25**（同じ分野を続けるより、まぜたほうが定着する）、
毎回同じ順番にならないよう少しだけランダムを足します。画面には「なぜこの問題か」をいつも表示します。

- **ちょうどよい難しさ**: 新しい問題は「正解できそうな確率」が 75% に近いほど加点します。
  苦手な分野では、自然とやさしめの問題から出ます
- **苦手度**: 習熟度（後述）が 80% 以上なら 0、0% なら 1。「苦手」と表示するのは3問以上解いてから

### 2. 記憶のモデル: 間隔反復（`src/fsrs.js`）

[FSRS-6](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm) を使っています（式と初期パラメータは ts-fsrs 6.0.0 と同じ）。

- 問題ごとに **安定度 S**（思い出せる確率が 90% まで下がるのにかかる日数）と **難しさ D**（1〜10）を持ちます
- 思い出せる確率: `R(t) = (1 + F·t/S)^(-decay)`
- 答えるたびに、評価（1 だめ / 2 むずかしい / 3 できた / 4 かんたん）で S と D を更新します。
  忘れかけてから思い出したほうが、S が大きくのびます

評価は自分で選ばなくても、結果から自動で決めます（`src/grade.js`）。

| 結果 | 評価 |
| --- | --- |
| まちがい | 1 だめ |
| ヒントを見た・部分点・目安の1.5倍より時間がかかった | 2 むずかしい |
| 目安の35%より早く正解（初めての選択問題は、まぐれもあるので除く） | 4 かんたん |
| それ以外の正解 | 3 できた |

まぐれで当たったときは「まぐれだった」ボタンで「だめ」になおせます。

### 3. 苦手の推定（`src/mastery.js`）

Elo レーティングを使います。分野ごとの **実力 θ** と問題ごとの **難しさ b** から、
`正解する確率 P = 1 / (1 + e^-(θ − b))` と考え、答えるたびに「結果 − P」だけ両方を動かします。

- まだ解いていない問題でも、正解できそうな確率がわかる（→ ちょうどよい難しさの問題を選べる）
- **習熟度** = ふつうの難しさの問題に正解できる確率 = `1 / (1 + e^-θ)`
- 動かす幅は、回数が少ないうちは大きく、だんだん小さくします

### 4. 記録の設計（`src/store.js`）

**起きたことだけを、追記専用のログに1行ずつ書く**（イベントソーシング）。状態は保存しません。

```jsonl
{"id":"…","at":"2026-11-05T01:00:00.000Z","type":"attempt","itemId":"java/loop-for","rev":"3f2a9c1d","sessionId":"web-…","answer":"012","correct":true,"score":1,"grade":3,"latencyMs":8123,"hintUsed":false,"gradedBy":"auto"}
{"id":"…","at":"…","type":"override","attemptId":"…","grade":1}
```

| type | 意味 |
| --- | --- |
| `attempt` | 1回答えた（答え・正誤・点数・評価・かかった時間・ヒントの有無・だれが採点したか） |
| `override` | 評価をなおした（まぐれだった） |
| `suspend` | 問題を止めた／もどした |
| `item` | 問題を追加した（AI が作った問題） |
| `params` | 記憶モデルのパラメータを自分用に調整した |
| `daily` | 定期実行した日 |

こうしておくと:

- アルゴリズムやパラメータを変えても、**過去の記録から全部計算しなおせる**
- 自分の記録に合わせて **パラメータを調整できる**（下の tune）
- 「まぐれだった」でなおしても、その後の計算がすべて正しく変わる
- 途中で落ちてこわれるのは最後の1行だけ（読みとばして、次は新しい行から書く）
- 問題の内容の指紋（`rev`）も残すので、問題を書きかえたあとでも、どの版に答えたかわかる

### 5. 自分用の調整（`src/tune.js`）

最初のパラメータは「大勢の平均」です。復習の記録が50件たまると、週に1回（定期実行のとき）、
**予想した確率と実際の結果のずれ（log loss）が小さくなるように** パラメータを探しなおします。
ずれが1%以上へったときだけ使います。手で動かすときは `node bin/coach.js tune`。

### 6. 定期実行（`src/daily.js`）

1日1回、次のことをします。

1. 苦手な分野で、まだ解いていない問題が3問未満なら、AI に3問ずつ作ってもらう（最大2分野。まちがえた問題も参考にわたす）
2. 週に1回、自分用の調整
3. 今日の予定とふり返りを `data/reports/YYYY-MM-DD.md` に書く
4. `COACH_WEBHOOK_URL` があれば、そこに送る（Discord / Slack の Webhook）

同じ日に何回呼ばれても実行するのは1回だけ（`--force` で強制）、2つ同時には動かない（ロックファイル）ので、
どの方法で呼んでも安全です。

- **`npm start`（serve）が動いているあいだ**: 毎分たしかめて、`dailyAt`（ふつう 07:00）をすぎていて今日まだなら実行。
  PC がスリープしていて時刻をのがしても、起きたときに実行します
- **PC のスケジューラから**: 次のコマンドが、この PC のパスを入れた cron / launchd / タスク スケジューラの設定を表示します

  ```bash
  node bin/coach.js schedule
  ```

## コマンド

| コマンド | すること |
| --- | --- |
| `node bin/coach.js serve` | 画面（`npm start` と同じ） |
| `node bin/coach.js quiz [n]` | ターミナルで n 問 |
| `node bin/coach.js daily [--force]` | 定期実行を1回（`npm run daily`） |
| `node bin/coach.js stats` | 分野ごとの習熟度・これから7日の復習 |
| `node bin/coach.js tune` | 自分の記録で記憶モデルを調整 |
| `node bin/coach.js schedule` | 毎日動かす設定のしかた |

| 環境変数 | |
| --- | --- |
| `ANTHROPIC_API_KEY` | AI を使うとき |
| `COACH_MODEL` | AI のモデル（ふつう `claude-opus-5-5`） |
| `COACH_DATA_DIR` | 記録のフォルダ（ふつう `coach/data`） |
| `COACH_PORT` | 画面のポート（ふつう 4310） |
| `COACH_WEBHOOK_URL` | 定期実行のまとめを送る先 |

設定は `data/config.json` で変えられます（書かなかった項目はふつうの値）。

```json
{ "targetRetention": 0.9, "newPerDay": 10, "relearnGap": 3, "cooldown": 4, "dayStartHour": 4, "dailyAt": "07:00" }
```

`targetRetention` を上げると復習が増えて忘れにくく、下げると復習が減ります。学習の「1日」は朝4時に切りかわります。

## 問題集を足す

`decks/` か `data/decks/` に JSON を置きます（自分だけの問題は `data/decks/` に）。問題の id は「問題集id/問題id」になります。

```json
{
  "id": "mydeck",
  "title": "自分の問題",
  "tags": { "sql": "SQL" },
  "items": [
    { "id": "q1", "tag": "sql", "type": "choice", "level": 2, "prompt": "行を取り出す命令は？",
      "choices": ["SELECT", "INSERT", "DELETE"], "answer": 0, "explanation": "…", "hint": "…" },
    { "id": "q2", "tag": "sql", "type": "input", "prompt": "…", "code": "…", "answers": ["3", "3行"] },
    { "id": "q3", "tag": "sql", "type": "free", "prompt": "…を説明して", "model": "模範解答", "rubric": "採点のポイント" }
  ]
}
```

- `type`: `choice`（`answer` は0からの番号）/ `input`（`answers` のどれかと同じなら正解。空白・全角半角は無視。`"ignoreCase": true` で大文字小文字も無視）/ `free`（AI か自己採点）
- `level`: 1〜5（最初の難しさの見こみ。解かれるうちに自動で調整されます）
- `timeSec`: 答えるのにかかる目安の秒数（ふつう choice 20 / input 30 / free 120）
- 問題の id は変えないでください（記録と問題を id でつないでいます）。問題を消しても記録は残ります
